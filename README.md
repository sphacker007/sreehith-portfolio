# Sreehith Yachamaneni — Data Scientist Portfolio

A responsive editorial portfolio built with Next.js App Router, TypeScript, Tailwind CSS, Framer Motion, and Lucide.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Checks

```bash
npm run build
```
